🍄 Gnome Garden Defense 🎮

Build gnomes to defend your cabbage from hungry slugs!

📝 To Play the Full Game Locally:

1. Open VS Code with your Andrew-website folder

2. Create a file called gnometowerdefense.html

3. Paste the full Gnome Garden Defense game code into it

4. Right-click on the file → "Open with Live Server"

5. Play the complete game! 🚀

Game Features

  • 7 Tower Types: Standard, Splash, Frost, Fire, Anti-air, Sniper, Machine gun
  • 30 Challenging Waves: Normal, Fast, Shielded, Boss, and Flying slugs
  • Special Abilities: Salt Storm and Fire Storm
  • Tower Upgrades: Boost your defenses with 3 upgrade levels
  • Hard Mode: Limited coins and fast-paced gameplay
